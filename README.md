# ECG Viewer для Flipper Zero

**Статус: тестовый режим.**

Приложение отображает сигнал с аналогового входа PC0 на экране Flipper Zero. Опрос АЦП выполняется отдельно от отрисовки с целевой частотой 250 отсчётов/с; каждые десять отсчётов объединяются в один столбец графика по минимуму и максимуму. Экран обновляется примерно 25 раз/с.

## Управление

- Вверх / вниз — масштаб графика.
- Влево / вправо — сдвиг графика.
- Назад — выход.

`!` в заголовке означает, что при работе приложения хотя бы один срок измерения был пропущен.

## Сборка

Приложение собрано с uFBT под Flipper Zero SDK 1.3.4 (target 7, API 86.0). Готовый файл — [`ecg_viewer_v2.fap`](ecg_viewer_v2.fap). Для сборки из исходников запустите `ufbt` в корне проекта с SDK этой версии.

Проверка логики обработки сигнала на Linux:

```sh
cc -std=c11 -Wall -Wextra -Werror -fsanitize=address,undefined -I src tests/test_signal.c src/ecg_signal.c -o ecg-signal-test
./ecg-signal-test
```
